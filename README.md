## About
Frontend Engineer specializing in **interactive 3D web experiences**. I build immersive, performant interfaces with **Three.js**, **WebGL**, and **React Three Fiber**, on a solid foundation of **React**, **TypeScript**, and **Next.js**.

Self-taught in **Blender**, I bridge 3D modeling and the web — taking scenes from model to real-time render in the browser with GSAP-driven camera work and raycasting-based interaction. Biomedical Engineering background from Cairo University, now focused on real-time 3D and creative frontend development.
